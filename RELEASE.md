# FM Control RC1

## RC1-001 / RC1-002

### Estado
Estable para prueba.

### Objetivo
Eliminar el scroll innecesario en los workspaces principales de Etiqueta y Camión.

### Cambios
- Workspace de Nueva Etiqueta ampliado al 94% del ancho y 92% del alto.
- Etiqueta reorganizada en tres columnas: datos, producción y vista previa.
- Vista previa de etiqueta visible en todo momento.
- Workspace de Camión ampliado al 94% del ancho y 92% del alto.
- Camión reorganizado con KPIs superiores, historial izquierdo, mapa central y detalle derecho.
- Scroll vertical global eliminado en ambos workspaces.
- El scroll queda limitado a listados internos como historial de cajas o listado de camiones.

### Validación técnica
- Build ejecutado correctamente con `npm run build`.
