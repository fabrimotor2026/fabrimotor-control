# modules

Arquitectura por dominios de FM Control.

Cada módulo debe contener su propia interfaz, lógica y utilidades cuando pertenezcan a un dominio funcional concreto.

Módulos actuales/preparados:

- `dashboard`: dashboard inteligente del camión.
- `trucks`: gestión de camiones.
- `search`: futuro buscador global.
- `operators`: futura ficha del operario.
- `statistics`: futuras estadísticas de producción.
